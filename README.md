# Dear Teacher !

Website permintaan maaf interaktif untuk guru Bahasa Inggris.

## Struktur folder
- `index.html` : struktur halaman website.
- `style.css` : tampilan dan animasi.
- `script.js` : interaksi dan kontrol musik.
- `assets/music/` : tempat file musik milikmu.

## Memasang musik
1. Masukkan file musik MP3 milikmu ke `assets/music/`.
2. Ubah nama file menjadi `apology-song.mp3`.
3. Buka `index.html` menggunakan Live Server.

Jika kamu ingin menggunakan nama file musik lain, ubah path sumber audio pada bagian `<audio>` di `index.html` agar sesuai.
